# LUNA FLOWERS

Сайт цветочной мастерской с каталогом букетов, подбором композиции и формой индивидуального заказа. Проект построен на React, TanStack Start, Vite и Nitro.

## Локальный запуск

Нужен Node.js и npm. Установите зависимости и запустите сервер разработки:

```bash
npm ci
npm run dev
```

Адрес сайта появится в терминале после запуска.

## Заявки

Формы сайта отправляют заявки в Telegram через маршрут `/api/leads`. Для работы заявок скопируйте `.env.example` в `.env.local` и заполните:

| Переменная | Назначение |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | Токен Telegram-бота |
| `TELEGRAM_CHAT_ID` | ID чата, в который приходят заявки |
| `SITE_URL` | Публичный адрес сайта для ссылок и SEO |

Бот должен быть добавлен в нужный чат. После настройки переменных перезапустите сервер разработки.

## Структура проекта

- `src/routes` - страницы и маршрут для заявок.
- `src/components` - компоненты интерфейса.
- `src/data` - данные каталога и конструктора букета.
- `src/lib` - общая логика и серверная обработка заявок.
- `src/styles.css` - стили сайта.
