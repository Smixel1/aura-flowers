# LUNA FLOWERS

Сайт-каталог букетов на React, TanStack Start, Vite и Nitro. Посетители могут выбрать букет, заказать индивидуальную композицию или оставить сообщение. Заявки отправляются серверным маршрутом в Telegram. Базы данных, личного кабинета и административной панели в текущем коде нет.

## Локальный запуск

```bash
npm ci
npm run dev
```

Проверки:

```bash
npm test
npx tsc --noEmit
npm run lint
npm run build
npm audit --omit=dev
```

## Заявки в Telegram

Маршрут `POST /api/leads` проверяет размер и поля заявки, затем вызывает Telegram Bot API. Браузер получает успешный ответ только после подтверждения Telegram. Токен бота никогда не должен иметь префикс `VITE_` или находиться в репозитории.

В настройках проекта Vercel откройте **Settings → Environment Variables** и добавьте:

| Имя | Значение |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | Токен бота, созданного через BotFather |
| `TELEGRAM_CHAT_ID` | ID чата или группы, куда бот может отправлять сообщения |
| `SITE_URL` | Основной публичный адрес сайта для SEO, например `https://example.com` |

Для тестового развёртывания выберите **Preview**, для рабочего сайта **Production**. После изменения переменных требуется новое развёртывание. Не отправляйте токен в чат или GitHub. В локальной разработке можно использовать `.env.local`; образец имён переменных находится в `.env.example`.

В коде есть локальное ограничение числа запросов по IP из заголовка, установленного площадкой (`X-Vercel-Forwarded-For` на Vercel). Память отдельных серверных функций не общая, поэтому настройте распределённый rate limit для `/api/leads` в Vercel Firewall перед открытием публичного приёма заявок.

## Развёртывание

Сборка на Vercel автоматически выбирает Nitro preset `vercel`. Локальная сборка без переменной платформы использует Cloudflare preset по умолчанию в обёртке Lovable. Для проверки Vercel-артефакта локально: `$env:VERCEL='1'; npm run build` в PowerShell. Это создаёт `.vercel/output/functions/__server.func`.

Прежние инструкции про n8n и Neon относились к планируемой архитектуре и не описывали текущий сайт.
